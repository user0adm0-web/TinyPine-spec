# Documentos de trabalho do canvas

Estes arquivos **não fazem parte da especificação** (não estão em `spec/`, e o build e o `tools/check.py` não os leem).
São o histórico e o material de apoio do módulo `canvas`, copiados **sem alteração** dos rascunhos v3:

| **Arquivo**                                  | **O que é**                                                                 |
|----------------------------------------------|-----------------------------------------------------------------------------|
| `canvas-08-arquitetura.md`                   | como o motor pode ser construído (camadas, backends, C#/.NET, marcos)       |
| `canvas-09-pesquisa.md`                      | pesquisa sobre motores de interface e o que cada um ensina                  |
| `canvas-10-decisoes-em-aberto.md`            | decisões D01–D58 (as do autor, as da spec e as aplicadas por padrão)        |
| `canvas-11-mudancas-v2.md`, `canvas-16-mudancas-v3.md` | o que mudou de uma versão dos rascunhos para a outra              |
| `canvas-12-analise-v2-e-preparacao-v3.md`    | análise da v2 (defeitos F1–F8, lacunas, perguntas D38–D51)                  |

O texto normativo do módulo está nos Capítulos 43 a 53 da especificação. Nestes arquivos, as referências a `canvas-NN-*.md` e as marcas `(Dnn)` apontam para os rascunhos, que já não existem como arquivos separados; o mapa é:
`canvas-00` → Cap. 43, `01` → 44, `02` → 45, `03` → 46, `13` → 47, `04` → 48, `05` → 49, `15` → 50, `14` → 51, `06` → 52, `07` → 53.
